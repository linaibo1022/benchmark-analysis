# benchmark-analysis

把 12 道题的评分数据，变成三张表 + 三张图 + 一段能写进简历的结论。

## 三步

1. 填 `data/items.csv`（每题每题模型一行，共 24 行）
2. 填 `data/runs.csv`（豆包五次采样，12 行）
3. 运行

```powershell
cd benchmark-analysis
python analyze.py
```

先看效果可以跑预览（合成数据，不动你的文件）：

```powershell
python analyze.py --demo
```

输出在 `output/`：`analysis.md` 和三张 png。

## 填表规则

`items.csv` 每一行 = 一道题 × 一个模型：

| 列 | 填什么 |
|---|---|
| `item_id` | Q1…Q12，已预填，别改 |
| `title` | 题目编号（已脱敏，如 `Q1`） |
| `prompt_type` | `S` / `R` / `A` / `P` 之一 |
| `model` | `gpt` / `doubao`，已预填 |
| `def_score` | 定义恢复得分 |
| `reason_score` | 数学推理得分 |
| `pres_score` | 表达严谨得分 |
| `total` | 总分（三轴之和，满 10） |
| `error_tags` | 分号分隔，如 `E1;E3`；没有就留空 |
| `note` | 备注，可空 |

**注意**：三轴相加必须等于 `total`，否则表 1 和表 4 会对不上。

`runs.csv`：每行一道题，`run1`–`run5` 是豆包五次独立评分。

## 输出怎么读

**表 4（题面类型 × 平均分）是结论的主要来源。** 读法：

- **S > R > A ≈ P**：定义恢复是主要瓶颈，不是推理能力
- **GPT 与豆包在 S 上接近、在 P 上拉开**：差距来自“读论文定义”而不是“做数学”
- **各类型差距都很小**：说明题目没有区分度，需要换题

**表 3（错误标签频次）**：如果 `E1 definition drift` 在豆包侧显著高，就和表 4 互相印证。

**表 5（稳定性）**：极差 > 2 分的题，单次得分不可信，结论里要单独说明。

## 注意

- 这个脚本只做统计和出图，不做解释。结论要你自己写，而且要能被表里的数字支撑。
- `--demo` 的分数是编的，只用来预览格式，不要截图当结果。
