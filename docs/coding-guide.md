# 过程指标填写说明

目标：用「第一个失效的环节」替代总分，绕开 GPT 满分带来的天花板效应。

> 注意：早期版本还有一个 `first_fail`（第一个失分的 rubric 编号）字段，已废弃——各题 rubric 结构不统一（有的用 R1–R8，有的用 D/R/P 或 L/M/C），编号跨题不可比。现在只保留两个可比字段。

## 两个字段

| 字段 | 取值 | 含义 |
|---|---|---|
| `fail_layer` | `L0` / `L1` / `L2` / `L3`，留空 | 首个关键错误/遗漏所属层级；无首错留空 |
| `missing_steps` | 整数 | 回答中「rubric 要求但未写出」的必要步骤数（见 §10.5） |

## 层级映射（按语义，不是按固定编号）

| 层 | 判据 |
|---|---|
| `L0` 定义 | 没有识别出论文中的目标对象，或用了别的定义（领域级漂移） |
| `L1` 构造 | 关键构造、对应关系、编码转换没有建立或没有说明 |
| `L2` 推理 | 核心证明链条缺失、断裂或含错误推理 |
| `L3` 边界/严谨 | 边界情形、量词、有限性、唯一性、严谨性未处理 |

**判定顺序**：先看 L0，不满足就停；满足再看 L1；以此类推。同一份回答只归到一个层。

**严重性另记**：`fail_layer` 只记“在哪一层”，不记“有多糟”。同一层的轻微疏漏和致命漂移要分开判断——这正是评测结论里要写清楚的地方。

## 两个例子

**例 1：定义就错了**

```
fail_layer=L0, missing_steps=3
```
模型把题目里的目标对象理解成了另一个定义（例如把“非恒定函数类”当成“全体单调函数”），后面构造再漂亮也无效，直接在 L0 截止。

**例 2：满分但仍有缺步**

```
fail_layer=, missing_steps=1
```
结论和构造都对，但「空集标签的排除」只写了「显然」，属于 rubric 要求写出的步骤。分数仍是 10，但 `missing_steps=1`。
**这正是这个过程指标不饱和的原因**：满分答案之间也能比较。

## 填写顺序建议

1. 先填 GPT 的 12 行（每题一条，篇幅短）
2. 再填豆包的 12 行（每题用五次里**最好那次**定 `fail_layer`，`missing_steps` 同样取最好那次）
3. 填完跑 `python analyze.py`，看表 6 和表 7

## 三条纪律

1. **只看回答实际写了什么**，不替模型补证明（与 rubric 一致）。
2. **层内不做细分**，`L2` 里不区分具体是哪个证明步骤，否则样本太散。
3. **豆包用最好那次**，否则 Q7 那种 4/5 全错的题会掩盖「它其实能做对」的事实。
